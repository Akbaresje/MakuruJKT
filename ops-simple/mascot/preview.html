Catatan teknis

  • Semua gerak pakai satu loop rAF + CSS, jadi ringan (tidak ada library).
  • Bug di kode asli sudah saya betulkan: klik squash dulu ketimpa sama loop mata, sekarang tidak.
  • Kedipnya acak 2,4–5,6 detik, kadang kedip dua kali.
  • Kalau mouse diam > 2,6 detik, matanya jalan sendiri.
  • Hormati reduced motion: semua gerak berhenti, maskot tetap ada.

  • Tanpa emoji, tanpa file gambar — semuanya SVG inline.

D. Kalau kamu setuju

Rencana saya saat masukin ke app.

  • File baru ops-simple/mascot/ (CSS + JS), di-inline saat build — tetap satu file HTML.
  • Muncul di landing page + semua halaman app. Otomatis sembunyi saat modal terbuka supaya tidak menutupi tombol Delete.
  • Di HP: 88px, geser ke atas sedikit supaya tidak kena toast di bawah.
  • Sekali-kali saja dia ngomong (misal setelah simpan order): "Order saved." — pakai bahasa Inggris simpel, sama seperti UI.
  • Tombol "Pasang di pojok layar ini" di atas cuma buat tes di halaman preview ini.
